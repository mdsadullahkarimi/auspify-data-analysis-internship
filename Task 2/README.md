# Netflix Content Type Analysis Dashboard

## Project Overview
This project analyzes the distribution of Movies and TV Shows available in the Netflix dataset using Python.

## Objectives
- Load the cleaned Netflix dataset.
- Calculate the total number of Movies and TV Shows.
- Calculate content percentages.
- Create a professional bar chart.
- Summarize key findings.

## Tools Used
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Dataset
The analysis uses `cleaned_netflix_data.csv`.

## Key Results
- Total titles: 8,790
- Movies: 6,126 (69.69%)
- TV Shows: 2,664 (30.31%)

## Key Findings
Movies account for the majority of titles in the analyzed Netflix dataset. They represent 69.69% of the content, while TV Shows represent 30.31%.

## Project Files
- `Task2.py` — Python source code
- `Task2_Content_Type_Chart.png` — Content distribution chart
- `Task2_Summary_Report.txt` — Summary report

## Conclusion
The analysis shows that Movies make up a larger proportion of the Netflix titles in this dataset than TV Shows.
