
# Task 6: Netflix Business Insights Report

## Project Overview
This project analyses the Netflix dataset using Python and Pandas to generate business insights about content distribution, countries, genres, and catalog composition.

## Dataset
- Total titles: 8,790
- Total columns: 10
- Source file: `cleaned_netflix_data.csv`

## Analysis Performed
1. Dataset overview
2. Movies vs TV Shows distribution
3. Country-wise content analysis
4. Genre distribution analysis
5. Business insights and recommendations
6. Content type visualization

## Key Findings
- Movies: 6,126 (69.69%)
- TV Shows: 2,664 (30.31%)
- Top country by title-country associations: United States
- Most frequently listed genre: International Movies

## Tools Used
- Python
- Pandas
- Matplotlib

## Output Files
- `Task6_Business_Insights.txt`
- `Task6_Content_Type_Chart.png`
- `Task6.py`

## Limitations
A title can be associated with multiple countries or genres. Counts show catalog representation, not viewership, revenue, or audience preference.
