# Task 4: Trend Analysis by Release Year

## Project Overview
This project analyzes Netflix content by release year using Python. It identifies yearly content counts, growth and decline patterns, and historical trends.

## Objectives
- Organize Netflix content by release year.
- Calculate yearly content counts.
- Identify growth and decline trends.
- Find the year with the highest content count.
- Create a trend visualization.
- Generate business insights.

## Tools and Technologies
- Python
- Pandas
- Matplotlib

## Project Files
- `Task4.py` — Python source code for the analysis.
- `Task4_Yearly_Trend.png` — Yearly content trend chart.
- `Task4_Yearly_Ranking.csv` — Year-wise content ranking.
- `Task4_Business_Insights.txt` — Business insights report.

## Key Findings
- The dataset contains 8,790 Netflix titles.
- No missing values were found in the release year column.
- The peak release year in the dataset is 2018, with 1,146 titles.
- Content counts increased significantly between 2015 and 2018.
- Counts declined in the years represented after 2018.

## Important Note
The dataset contains release years only through 2021. The findings describe the available dataset and should not be treated as a complete picture of Netflix releases after 2021.

## How to Run the Project
Run this command from the main project folder:

```bash
python "Task 4/Task4.py"
```

Ensure that `cleaned_netflix_data.csv` is available in the main project folder and that Pandas and Matplotlib are installed.

## Conclusion
This analysis identifies 2018 as the peak release year in the dataset and visualizes yearly changes in Netflix content counts.
